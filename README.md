# اتوپلاس — نسخه اصلاح‌شده

- چهار اسلاید؛ سه تصویر + یک اسلاید متنی
- تعویض خودکار هر ۸ ثانیه
- در دسکتاپ متن کنار تصویر است
- در موبایل متن روی تصویر می‌آید
- دو تصویر ارسالی کاربر در `assets/` ذخیره شده‌اند
- تصویر سوم از LoremFlickr API گرفته می‌شود
- لوگوی داخلی SVG است و مشکل لود لوگوی قبلی ندارد
- آیکن سرویس‌ها از Iconify API می‌آیند
- آیکن بخش «دلار» داخلی و بدون وابستگی خارجی است

## اجرا

```bash
python3 -m http.server 8080
```

سپس: http://localhost:8080
